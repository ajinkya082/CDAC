TOYLAND TOYS ANIMATION PROJECT

How to run:
1. Extract the ZIP file.
2. Open the ToysAnimation folder in VS Code.
3. Open index.html in your browser, or use VS Code Live Server.
4. Hover over Robo Buddy, Sunny Teddy, or Zoom Racer to animate it.
5. To add sound, put your own royalty-free MP3 files into the sounds folder:
   sounds/robot.mp3
   sounds/teddy.mp3
   sounds/car.mp3

Animations work even when sound files are not provided. Browsers may require a user interaction before audio plays.
