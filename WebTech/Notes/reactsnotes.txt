*Hooks In React
-In react Hooks allows us to class component feature in function component.
-in react version-16 hookes introiduce.
-before using hooks in react first we have o import it.

Rules to use hooks 
-React hooks only work with function component not in class.
-in react hoooks can be render conditionally.
-in react hooks always write at top level component.

List of hooks 
1.usestate hook:
2.useEffect hook:
3.useref hook:
4.useContext hook:
5.useReducer hook:
6.useCallBack hook:
7.usememo Hook:

1.useState Hook:
-if you want to use state in function component for this we use useState hook.
-it return takes two parameter 1.currentState,2.function to update state
synatx:   const [currentState,functionToupdateState] = useState(values);

2.useEffectHook:
-useEffect is use to perform sideeffect in function component.
-sideeffect means fetching data from server,DOM ,manipulation and use of timers function.
-useEffect hook execute immediatly after component render.
-useEffect hook can perfom componentDidMount,ComponentDidUpdate,and componentwillUnmount lifecycle methode of class component.
-it takes two parameter 1.callback function,2.dependecy
syntax:useEffect(()=>{},dependecy);

Case1: if no dependecy value.
      useEffecthokk will execute after every component render.
syntax:useEffect(()=>{});
           
case2:when dependecy value pass as blank array, it will execute useEffect only once. it act as componentDidMount of class component lifecycle method.
syntax:useEffect(()=>{},[]);

case3: when we pass state or prop value as  dependecy, in this case use effect use execute once and after every time when state or property value change.
syntax:useEffect(()=>{},[state or props]);

-navigation of component 
-to perform routing in react we use react-router-dom library.

*types of routing 
1.naming routing:display component view after writting routing path name in browser url.

2.default routing:display component view when routing path is black.

3.parameterize routing:display component view when we pass parameter with routing path.

4.child routing : display one routing inside another routing, to perform this routing we use children property in routing object and again write routing login in it. to display child routing component view in parent routing component we have to import <Outlet/> directory in parent routing component .

5.whildcard routing:whe user enter wrong routing path in browser url then we display output of this routing component.make sure that whildcard routing must be always last routing in order, its below routing will never work.
